# ناظم — فهرس المعرفة المستقل لمفيد

هذه حزمة تجريبية داخلية لإنشاء نسخة معرفية قابلة للقراءة من **فهرس المواد المنشورة** في مجلة صيد. وهي منفصلة عن موقع الإنتاج ونظام البحث التقليدي وعن مهام «المدير مفيد».

## نطاق هذه الحزمة

- تقرأ حصريًا ملفات الفهرسة العامة الحالية داخل docs/assets/search/ (اللغات ar/en/fr والمقاطع المشار إليها).
- تتحقق من بنية الفهارس، حجم كل مقطع، بصمته SHA-256، عدد السجلات، تفرد الروابط، وحصرها بروابط المقالات المنشورة.
- تصدر ملف knowledge.jsonl مستقلًا بكل سجل لغوي وحقوله المعلومة، وتقريرًا quality_report.json عن الفجوات.
- تترك البلد، نوع المادة، المصادر الأصلية، حالة حداثة المعلومات، تاريخ آخر تحديث وروابط الترجمات **غير مؤكدة** بدل تخمينها.
- تتعامل مع ترجمات الموضوع نفسه كسجلات لغوية منفصلة إلى أن يُتحقق من الربط التحريري الصريح.

## حدود الحماية

**هذه الحزمة لا تنشر شيئًا ولا تعدّل أي ملف داخل المستودع.** لا تستدعي API، ولا تتصل ببريد أو حساب أو لوحة إدارة أو مصادر داخلية. وتمنع حفظ المخرجات داخل المستودع حتى لا تُنشر تلقائيًا عبر GitHub Pages. لا ينبغي دمج هذا الفرع قبل استكمال مراجعة البيانات والاختبارات على نسخة حديثة من المستودع.

## التشغيل المحلي (بعد جلب المستودع)

من جذر المستودع:

~~~bash
python3 tools/nazim_knowledge/build_index.py --dry-run
python3 tools/nazim_knowledge/build_index.py --out-dir /tmp/sayd-mufid-knowledge
python3 -m unittest discover -s tools/nazim_knowledge -p 'test_*.py' -v
~~~

التقرير يبيّن عدد السجلات، وغياب النص أو الصورة أو التاريخ أو الكلمات المفتاحية، وعدد السجلات التي لا تملك تصنيفًا أدق من «الأرشيف». **لا يُفسر تاريخ النشر بوصفه إثباتًا لحداثة المحتوى.** يحتاج تدقيق المصادر والبلدان وربط الترجمات إلى عمل مستقل ومراجع.

## حدود المرحلة الحالية

هذه خطوة تجهيز الفهرس، وليست خدمة بحث مستخدمة من الجمهور. لم يُنفذ بعد البحث الدلالي أو إعادة ترتيب النتائج أو الربط بنموذج اللغة أو الـWorker أو واجهة «اسأل مفيد». كما أن نجاح الاختبارات على عينات اصطناعية لا يثبت نجاح معالجة كامل الأرشيف؛ يلزم تشغيل شامل للتقرير على نسخة المستودع الكاملة.

الاسمان المعتمدان: **«المدير مفيد»** للدور الداخلي، و**«مفيد»** للخدمة العامة. «ناظم» دور تقني داخلي غير معروض للجمهور.
