# البحث في أرشيف صور «صيد» (GitHub فقط)

**الحالة:** أُجري فحص شامل للأرشيف بتاريخ 10 تشرين الأول 2026. الأصل محفوظ داخل مستودع `unionmed/sayd-magazine`، ولا تُنقل الصور أو تُعاد تسميتها.

## نطاق الأرشيف
- 10,184 صورة بمسارات فريدة، جميعها موجودة وتطابق بصمتها المسجلة محتوى Git.
- 9,984 ملف صورة بمحتويات مختلفة، و200 مسار إضافي لمحتوى مكرر ضمن 96 مجموعة.
- 578 صورة تقترح أسماء ملفاتها بابًا تحريريًا؛ 9,606 صورة غير مصنفة بالاسم، لكنها مدرجة في البحث بالمسار.
- 729 ملف مقال فُحص؛ 81 إشارة محلية دقيقة تربط 77 صورة مختلفة بـ29 مقالًا. باقي المقالات لا ينبغي اعتبارها مرتبطة تلقائيًا.
- الصور الـ16 الموجودة خارج `docs/media/uploads/` ضمن الفهرس أيضًا.

## البحث
أوامر التشغيل من جذر المستودع:

```bash
python audit/image-catalog/search_all.py "صقر" --limit 20
python audit/image-catalog/search_all.py "" --section "الفروسية" --limit 30
python audit/image-catalog/search_editorial.py "سهيل" --limit 10
python audit/image-catalog/search_editorial.py "رماية" --limit 10
python audit/image-catalog/search_all.py --audit --check-files
```

البحث الأول يشمل كل المسارات الـ10,184 بلا استثناء. البحث التحريري يضيف عنوان المقال فقط إذا وُجد ربط محلي مباشر ودقيق مع صورة GitHub. نتائج التصنيف المرشحة مستخرجة من اسم الملف وليس من التعرف البصري.

## مصادر البيانات
تُستخدم ملفات صور GitHub ومقالات GitHub المحلية فقط. لا يجري الاستعلام من أي قاعدة بيانات خارجية أو مكتبة صور خارجية، ولا تُحتسب الروابط القديمة الخارجة عن مستودع GitHub كروابط مثبتة بين الصورة والمقال.

## ملفات النتيجة
- `manifest/*.tsv`: سجل المسار وحجم الملف وبصمته.
- `preliminary-taxonomy.json`: التصنيف المبدئي لكامل الأرشيف.
- `article-image-links.json`: الروابط الدقيقة بين صور GitHub ومقالاته، ومواضع الالتباس إن ظهرت.
- `coverage-report.md` و`coverage-report.json`: أرقام التحقيق النهائي.
- `search_editorial.py`: أداة الاسترجاع التحريري.
- `.github/workflows/archive-catalog.yml`: اختبار شامل قابل للتشغيل مجددًا دون تعديل الموقع.

## بروتوكول الاستعمال
عند إعداد مادة جديدة، يستخرج مفيد الصور المرشحة، يفتحها بصريًا، يفحص مطابقتها للمضمون ويحدد صفتها (صورة توثيقية أو توضيحية) ويتحقق من المصدر وحقوق الاستعمال قبل عرضها للمراجعة. لا يصح اعتبار اسم الملف دليلاً على نوع الحيوان، أو المصور، أو المكان، أو تاريخ التصوير.

**تنبيه:** هذا فهرس متكامل للملفات وليس وصفًا بصريًا مكتملًا لجميع الصور. لا تُعدل هذه العملية ملفات الموقع أو العناوين أو الصور الأصلية.

## مسار الإضافات التراكمي

راجع `INCREMENTAL-PUBLICATION.md`: الصور الجديدة تُسجَّل في ملف TSV جديد صغير
لكل حزمة، ولا يُعاد تحرير الفهارس التاريخية. ملفات JSON والتغطية القديمة أعلاه
لقطات تاريخية؛ النتائج الحديثة تُبنى في `.catalog-build/`، والبحث التحريري يقرأ
المقالات والفهرس التراكمي مباشرة ويحفظ أدلة المراجعة الموروثة منفصلة.
