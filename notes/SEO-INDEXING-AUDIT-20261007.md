# تدقيق تنبيهات الفهرسة — 7 تشرين الأول 2026

الحالة: تصحيحات مقترحة للمراجعة فقط؛ لا دمج ولا نشر دون اعتماد نايف.
المرجع: main عند 0b03f047f، ورسالتا Google الأصليتان في بريد Union Media بتاريخ 7 أكتوبر.

## ما ثبت

- التنبيه العام يذكر Duplicate, Google chose different canonical than user. تنبيه الصفحات في sitemap يضيف noindex والتحويل. لا تورد الرسالتان أمثلة URLs أو أعدادًا؛ لا يمكن نسبة السبب لصفحة بعينها من البريد.
- اتصال Search Console المتاح أعاد قائمة خصائص فارغة؛ تعذر الحصول على Google-selected canonical أو أمثلة تقرير الاستبعاد.
- محاولة استرجاع الرئيسية ومصر في AR/EN/FR وصفحة تحويل وصفحة noindex عبر HTTP أعادت 403 من بيئة الوصول. هذا حد للتحقق الحي، وليس دليلًا أن Googlebot يتلقى 403.
- خريطة main تحتوي 871 رابطًا فريدًا. أربعة منها تحويلات أقسام عربية إلى قسم صيد: صيد-بري، صيد-بحري، صيد-الطيور، الصقارة. التحويل وcanonical الوجهة صحيحان؛ الخطأ هو إدراج روابط التحويل في sitemap.
- المستودع يحتوي 734 صفحة meta refresh و22 صفحة noindex؛ هذه أعداد ملفات محلية وليست أعداد Search Console. صفحات الأرقام والأسماء البديلة والصفحات الملغاة تحويلات مقصودة؛ بطاقات الصور وبعض الأقسام الفارغة مستبعدة عمدًا. لم يثبت وجود noindex في رابط من الخريطة.
- مثال noindex مقصود: posts/سهيل-2026-بالصور-الصقور-والزوار-ووجوه-ا/index.html، وهو بطاقة صور مستبعدة من الخريطة. مثال تحويل مقصود: 6719/index.html؛ التحويلات HTML بسبب استضافة GitHub Pages ولا تعني HTTP 301.
- لمادة مصر canonical ذاتي مستقل وروابط AR/EN/FR وx-default متبادلة في النسخ الثلاث؛ لا noindex أو meta refresh عليها في المستودع.
- فحص أهداف hreflang في المستودع لم يجد ملفات أهداف مفقودة. فحص التبادل أظهر 16 رابطًا فرنسيًا إلى صفحات EN دون عودة: license، stories، about، و13 صفحة أقسام. بعضها يقود إلى صفحات أقسام EN تحويلية. هذه فجوات إعداد موجودة تحتاج مراجعة ربط صفحات الأقسام والمرايا، ولا تثبت أنها سبب رسالة Google. لا يشمل PR إعادة تنظيم المرايا أو التحويلات؛ يوثق الفجوة للمتابعة.

## التصحيح المقترح

1. يقرأ مولد lastmod سجل content/article-updates.json مرة واحدة ويستخدم آخر تاريخ مسجل لكل مرآة، دون النزول تحت تاريخ النشر. مادة مصر تصبح 2026-10-07 في AR/EN/FR. الصفحات غير المسجلة تبقى على تاريخها المنشور.
2. يقرأ أسماء الأشهر الفرنسية، حتى لا تسقط تواريخ فرنسية موجودة عند إعادة توليد sitemap. تضاف تواريخ نشر فعلية كانت ناقصة، ولا يستعمل تاريخ اليوم أو تاريخ تعديل الملفات.
3. تستبعد روابط الأقسام التحويلية الأربعة من sitemap فقط. تصبح الخريطة 867 رابطًا فريدًا. يحافظ إعادة التوليد على مجموعة الروابط الأخرى ويعيد ترتيب XML فقط.
4. لا تغيير في HTML المنشور أو تاريخ النشر أو ترتيب المواد أو homepage أو canonical أو hreflang أو noindex أو سلوك التحويل.

## التحقق

نجحت فحوص عقد النشر مع --base origin/main، وأبواب الرئيسية، ووسائط الأرشيف، والوصول للأرشيف. نجحت اختبارات تاريخ التحديث، وعدم رجوع التاريخ، والأشهر الفرنسية، وربط سجل مصر باللغات الثلاث واستبعاد روابط الأقسام الأربعة.
نجح فحص جميع روابط الخريطة الـ867: لا تكرار، canonical ذاتي واحد، ولا meta noindex أو refresh.

فحوص SEO القديمة: 13 نجاحًا و4 إخفاقات قبل اختبار apply الذي يعيد كتابة HTML. تكررت الحالات الأربع مع أداة SEO الأصلية دون تعديل HTML: test_home_and_memory_twins يفترض صورة قديمة، test_gallery_cards_are_not_indexed_articles يفترض بطاقة قديمة، test_empty_category_doors_leave_chrome_and_sitemap يفترض الصقارة ضمن الأقسام الفارغة، test_every_html_page_has_canonical يعتمد مطابقة نصية لا تتعرف على كل أشكال الوسم؛ فحص DOM وجد canonical لكل صفحة ذات head. لم تُضعف هذه الاختبارات أو تُعدّل لتجاوزها.

## ما يبقى غير محسوم

لا يمكن تحديد صفحات Duplicate أو canonical الذي اختارته Google دون أمثلة من تقرير Search Console وفحص URL Inspection. تصحيح lastmod ليس إثباتًا لحل الاستبعادات أو ضمانًا للفهرسة. يلزم الوصول إلى الخاصية أو تصدير أمثلة الاستبعاد، ثم مقارنة declared canonical مع Google-selected canonical وتاريخ آخر زحف. لا تزال مطابقة الموقع الحي مع المستودع غير محسومة بسبب حد الاسترجاع المذكور.
