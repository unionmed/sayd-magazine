# Sayd Photo Archive Protocol

This is the permanent operating reference for the Sayd image bank.

## Core rule

- Archive first: search the internal Sayd photo archive before external web image search for every story, update, carousel, Reel, Short, or other editorial asset.
- Nayef does not need to explicitly ask for an archive image; archive retrieval is part of the normal editorial workflow.
- If no suitable archived image exists, search externally and archive verified reusable material when appropriate.
- Never assign an image to an event, country, person, or authority unless provenance matches.

## Main archive structure

- `00_INBOX - To Sort`
- `01_Anti-Poaching & Violations`
- `02_Birds & Wildlife`
- `03_Hunting`
- `04_Shooting & Gear`
- `05_Equestrian`
- `06_Camping & Outdoors`
- `07_People & Interviews`
- `08_Archive & Memory`
- `09_Social & Screenshots`

Preferred path: `Section / Country / Region / YYYY-MM-DD_Event_Source`

Preferred filename: `YYYY-MM-DD_COUNTRY_REGION_SUBJECT_SOURCE_XX.ext`

Example: `2026-10-01_LB_Bekaa_Illegal-Nets_Adonis_01.jpg`

## Metadata to preserve when known

- Country and location
- Event/publication date
- Issuing authority, photographer, or source
- Short description
- Rights/reuse status
- Related published Sayd story, if any
- Status of linked figures/claims: confirmed or pending

## Official-source priority

Prioritize original images from security services, environment ministries, wildlife authorities, reserves, hunting/fisheries regulators, and official national agencies in Arab countries. Preserve the original source whenever possible.

## Editorial retrieval

When preparing a story, search by subject + country + event + source + date. Propose the strongest suitable archived image before external search. Nayef is not expected to remember the archive contents or filenames.

## Periodic harvesting

Periodically scan official Arab sources for useful new imagery. Avoid duplicates. Put uncertain or unclassified material in `00_INBOX - To Sort` until reviewed.
## Local-copy / no-hotlink rule

- Every image selected for the Sayd archive or for publication must be stored as a LOCAL COPY in the Sayd archive or website media before use.
- Never rely on an external image hotlink in a published Sayd article, card, Reel asset, or internal archive record. External URLs are source/provenance references only.
- If the exact event image cannot be downloaded, keep the event folder and source record with status `PENDING LOCAL COPY`; do not substitute an older, generic, or lookalike image as if it depicts the event.
- When the local copy becomes available, update the event folder and use that internal asset for publication.
